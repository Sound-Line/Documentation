# Frontend Sound Line

## Описание

Frontend музыкального сервиса Sound Line написан на React.

Он отвечает за интерфейс пользователя, отображение треков, загрузку музыки и воспроизведение аудио.

## Используемые технологии

- React
- JavaScript
- JSX
- Vite
- CSS
- Lucide React

## Основные компоненты

### App.jsx

Главный компонент приложения.

Отвечает за:
- переключение между страницами;
- хранение выбранного трека;
- отображение музыкального плеера.

### Sidebar.jsx

Боковое меню приложения.

Содержит переходы между основными разделами:
- Главная;
- Поиск;
- Загрузить трек;
- Моя медиатека.

### MyLibrary.jsx

Страница «Моя медиатека».

Здесь отображаются треки и другие разделы медиатеки.

Треки загружаются с backend через API.

### UploadTrack.jsx

Страница загрузки нового трека.

Пользователь выбирает аудиофайл, вводит название и имя исполнителя.

Frontend автоматически определяет длительность файла и отправляет данные на backend.

### Player.jsx

Музыкальный плеер.

Поддерживает:
- Play / Pause;
- перемотку;
- отображение времени;
- регулировку громкости;
- mute;
- повтор трека.

Плеер появляется после запуска трека.

## Работа с backend

Frontend использует три основных API:

```http
GET /api/tracks
```

Получение списка треков.

```http
POST /api/tracks/upload
```

Загрузка нового трека.

```http
GET /api/tracks/{id}/audio
```

Получение аудио для воспроизведения.

## Загрузка трека

При загрузке:

1. Пользователь выбирает аудиофайл.
2. Frontend проверяет его формат.
3. Определяется длительность трека.
4. Пользователь вводит название и исполнителя.
5. Данные отправляются на backend.

Поддерживаемые форматы:

- MP3
- FLAC
- WAV
- M4A

## Воспроизведение

После нажатия на карточку трека:

1. Трек становится текущим.
2. Появляется музыкальный плеер.
3. Frontend получает аудио с backend.
4. Начинается воспроизведение.

## Запуск

Установка зависимостей:

```bash
npm install
```

Запуск проекта:

```bash
npm run dev
```

После запуска сайт доступен по адресу:

```text
http://localhost:5173
```
