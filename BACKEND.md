# SoundLine

**SoundLine** — учебный проект музыкального веб-сервиса с возможностью загружать и слушать треки, создавать плейлисты и совместно слушать музыку в комнатах.

## Возможности

- Регистрация и вход пользователей с JWT-авторизацией.
- Загрузка и воспроизведение аудиотреков.
- Плейлисты и избранные треки.
- Комнаты совместного прослушивания: создание, приглашение по коду, участники и очередь.
- Передача состояния плеера и изменений очереди в реальном времени через SignalR.
- Серверное переключение треков и сохранение истории проигрывания.

## Технологии

| Часть проекта | Технологии |
|---|---|
| Интерфейс | React, Vite, JavaScript |
| Backend | C#, ASP.NET Core 10, Entity Framework Core |
| Связь в реальном времени | ASP.NET Core SignalR |
| База данных | PostgreSQL |
| Хранение аудиофайлов | MinIO |
| Запуск окружения | Docker Compose |
| Доступ команды к dev-серверу | Tailscale Serve |

## Репозитории проекта

- [SoundLine Backend](https://github.com/Sound-Line/soundline-backend) — API, авторизация, комнаты и SignalR.
- [Data](https://github.com/Sound-Line/Data) — структура PostgreSQL, миграции и Docker Compose.
- **Frontend** — интерфейс React 
- **Documentation** — документация проекта, включая таблицу контрактов HTTP API и SignalR.

## Как запустить

Для локального запуска Backend нужны репозитории **`soundline-backend` и `Data`**. Пошаговая инструкция размещена в файле **`INSTALL.md`** репозитория Backend. Фронтенд запускается отдельно из своего проекта.

После запуска Backend доступен по адресу `http://localhost:8080`; пример проверки — `GET /api/tracks`. Подробные поля запросов и ответов приведены в Excel-файле API-контрактов данного репозитория.
