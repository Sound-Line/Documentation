# Бизнес-требования: Sound Line

Документ описывает функциональные и нефункциональные требования к музыкальному стриминговому сервису Sound Line. Описывает **что** должен делать сервис, а не **как** он это делает.

## 1. Общее описание продукта

**Sound Line** — бесплатный музыкальный стриминговый сервис с возможностью загрузки треков пользователями (UGC) и совместного прослушивания в групповых комнатах.

## 2. Функциональные требования

### 2.1. Аутентификация и пользователи
- Регистрация по email и паролю.
- Вход в систему (JWT-токены).
- Выход из аккаунта.
- Вход через сторонние сервисы (Google / Apple / VK) — опционально.

### 2.2. Каталог музыки
- Просмотр списка всех треков.
- Просмотр детальной информации о треке (название, артист, длительность, альбом).
- Просмотр страницы альбома.
- Полнотекстовый поиск по трекам, артистам, альбомам.
- Подписка на артиста.

### 2.3. Воспроизведение
- Воспроизведение аудио в браузере.
- Пауза, продолжение, перемотка.
- Отображение прогресса и длительности.
- Регулировка громкости.
- Поддержка форматов: MP3, WAV.
- Очередь воспроизведения.
- Повтор трека / плейлиста.
- Shuffle (перемешивание).

### 2.4. Загрузка треков (UGC)
- Загрузка аудиофайла.
- Указание названия трека.
- Указание имени исполнителя.
- Автоопределение длительности.
- Автосоздание артиста, если его нет в БД.
- Валидация обязательных полей.
- Сообщения об ошибках загрузки.
- Прогресс загрузки.
- Загрузка обложки трека.
- Привязка трека к альбому.

### 2.5. Плейлисты
- Создание плейлиста.
- Редактирование (название, описание, обложка).
- Удаление плейлиста.
- Добавление трека в плейлист.
- Удаление трека из плейлиста.
- Лайк плейлиста.

### 2.6. Лайки и история
- Лайк / анлайк трека.
- Страница «Любимые треки».
- Автоматическая запись прослушиваний.
- Страница «Недавно слушал».
- Очистка истории.

### 2.7. Рекомендации
- Рекомендации на основе жанров пользователя.
- «Популярное сейчас».
- «Новинки от ваших артистов».

### 2.8. Комнаты группового прослушивания
- Создание комнаты (название, приватность).
- Приглашение по коду.
- Присоединение к комнате по коду.
- Роль ведущего (host) и гостей (guest).
- Ведущий управляет воспроизведением (play/pause/seek/next).
- Ведущий добавляет треки в очередь.
- Ведущий добавляет целый плейлист в очередь.
- Синхронизация воспроизведения у всех участников.
- Список участников комнаты.
- Список очереди треков.
- Выход из комнаты.
- Автопередача host'а первому гостю при выходе ведущего.
- Ручная передача host'а другому участнику.
- Автоматическое закрытие комнаты, если все ушли.
- Ограничение числа участников.
- История проигранного в комнате.
- Уведомления о смене host'а.
- Уведомления о новых участниках.
- Чат внутри комнаты.
